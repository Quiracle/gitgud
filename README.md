# GitGud

A browser-based daily game for learning Git by transforming simulated repositories.

The first implementation includes a purpose-built TypeScript Git engine and a basic puzzle UI. It does **not** execute real Git commands or access a filesystem.

## Supported simulator commands

```text
git switch <branch>
git checkout <branch>
git log
git log --all
git merge <branch>
git merge --ff-only <branch>
git cherry-pick <commit>
git revert <commit>
```

## Local development

```bash
pnpm install
pnpm dev
```

Run verification with:

```bash
pnpm test
pnpm build
```

The UI is intentionally foundational and will be redesigned separately. Simulation code lives under `src/engine` and does not depend on React.

By default, local development uses a validated bundled daily fixture. Copy `.env.example` to `.env.local` if you want to select the source explicitly.

## Daily AI generation and deployment

The official daily puzzle is generated by a scheduled Supabase Edge Function, validated by the same simulator used in the browser, and stored once per UTC date. The OpenAI request uses strict structured output and a configurable temperature that defaults to `1.8`.

Vercel hosts only the static Vite frontend; no Docker image or custom server is required. Follow [DEPLOYMENT.md](DEPLOYMENT.md) for the first-time Supabase, OpenAI, cron, fallback-pool, and Vercel setup.
